# Application API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Other programs on this machine can ask a running BE-Code session for a plain answer, an OpenAI-compatible completion, or an answer informed by that session's conversation, over a unix socket, with registered app keys and per-session tokens.

**Architecture:** `internal/api` is a leaf package (stdlib `net/http` on a unix socket) that knows nothing about agents: it authenticates registered apps, enforces budgets, and calls a narrow `Backend` interface. `internal/agent/api.go` implements that interface over the running `Agent` (tool-less chats through the model lane, a read-only snapshot of the conversation). `cmd/` wires the two, adds the `apps` and `session` commands, and the UIs add `/api`, `/apps` and `/session` slash commands. Session tokens live in `internal/store`.

**Tech Stack:** Go 1.25 stdlib only (`net/http`, `crypto/rand`, `crypto/subtle`, `encoding/json`), cobra for commands, Bubble Tea for the TUI. No new module dependencies.

**Spec:** `docs/superpowers/specs/2026-11-02-app-api-design.md`

## Global Constraints

- Version stays 1.3.1 (`build.mk`); this ships inside the unreleased 1.3.1.
- No new Go module dependencies; the JSON-schema check in §4.1 is a small built-in subset validator.
- Socket only: `~/.be-code/api/api.sock`, directory 0700, socket 0600; no TCP, no `api.listen` key.
- Any request with an `Origin` or `Sec-Fetch-Mode` header is 403 `browser_refused` before the body is read.
- Key format `bek_1_` + base64url(24 random bytes, unpadded); token format `sess_1_` + base64url(16 random bytes, unpadded). Only the SHA-256 of a key is stored, as `sha256:<hex>`.
- App names match `^[a-z][a-z0-9-]{1,31}$`.
- Error body is always `{"error": {"code": "<snake_case>", "message": "<text>"}}`; the codes are the spec's: `browser_refused`, `unauthorized`, `tier_not_allowed`, `sessions_not_allowed`, `session_not_found`, `session_not_running`, `session_mismatch`, `model_not_allowed`, `pack_not_allowed`, `rate_limited`, `over_budget`, `not_supported`, `schema_mismatch`, `context_too_large`, `session_busy`, `spend_cap`, `shutting_down`, `backend_error`, `bad_request`, `timeout`.
- No key or session token ever appears in the access log, a notice, a transcript entry, the chat or an error message.
- An API request is never a typed request: it must not call `BeginTypedRequest`, touch the inbox, the engine, the work ledger, or `History.Messages`.
- Headless `run` and `init` never serve. The server is started only by a UI after approvals are wired, and stopped first in `finishSession`.
- Commit messages follow `type(scope): summary` with present-tense body; `git add` named files only, never `-A` (two untracked scaffolding files, `k.pgp` and `x.txt`, sit in the tree). Run `make -f build.mk verify` before every commit that touches Go.

## Review Focus

Inputs the spec implies but no section's tests exercise, most likely to bite first. Each has a pinning test added to the task that owns the code.

1. **A key with the right prefix and wrong length, or non-base64 bytes.** Expected: 401 like any unknown key, with the 250 ms delay, never a 500 from a decoder. → Task 3.
2. **A `/v1/chat/completions` body with an empty `messages` array or a message whose `content` is an array of parts (the OpenAI vision shape).** Expected: 400 `not_supported` naming `messages`, not a backend call with nothing in it. → Task 5.
3. **An SSE client that disconnects mid-stream.** Expected: the backend call's context is cancelled within one delta, the lane is released, and the app's in-flight slot is freed so its next request is not 429. → Task 5 and Task 7.
4. **`X-BE-Session` sent to a stateless endpoint (`/v1/query`) by an app whose profile has `sessions: none`.** Expected: 403 `sessions_not_allowed`, so a misconfigured app learns at once; a `named` app sending it to a stateless endpoint gets the stateless answer (the header is ignored there). → Task 3.
5. **`apps add` run twice with the same name.** Expected: refused with the existing file named and no key printed; `apps rotate` is the way to get a new key. → Task 9.

	// Token addresses this session over the application API (spec
	// 2026-11-02-app-api-design.md §3). Minted lazily by AccessToken,
	// persisted with the session, never derived from ID or Code, never
	// shown in a listing or a log. PrevToken is the token before the last
	// Rotate, honoured until PrevUntil; both are empty when no grace
	// window is open.
	Token          string    `json:"token,omitempty"`
	PrevToken      string    `json:"prev_token,omitempty"`
	PrevUntil      time.Time `json:"prev_until,omitempty"`
	TokenRotatedAt time.Time `json:"token_rotated_at,omitempty"`
```

Note: `encoding/json` does not omit a zero `time.Time` under `omitempty`, so a session that
has never rotated carries `"prev_until": "0001-01-01T00:00:00Z"` once it has a token. That is
harmless (an older build ignores unknown fields, and `Accepts` treats a zero `PrevUntil` as
expired) and simpler than pointer fields; the test asserts only that the string fields are
omitted.

Create `internal/store/token.go`:

```go
package store

import (
	"crypto/rand"
	"crypto/subtle"
	"encoding/base64"
	"fmt"
	"time"
)

// tokenPrefix tags the token format so a later shape can be told apart.
const tokenPrefix = "sess_1_"

// MaxTokenGrace bounds how long a rotated-out token stays valid.
const MaxTokenGrace = 24 * time.Hour

// NewToken is a fresh session token: the format tag plus 16 bytes from the
// OS random source, base64url without padding. A random source that fails
// is a token nobody may trust, so it panics, as live.NewToken does.
func NewToken() string {
	var b [16]byte
	if _, err := rand.Read(b[:]); err != nil {
		panic("store: random source failed: " + err.Error())
	}
	return tokenPrefix + base64.RawURLEncoding.EncodeToString(b[:])
}

// AccessToken is the session's token, minted on first use. Nothing else
// reads the field directly.
func (s *Session) AccessToken() string {
	if s.Token == "" {
		s.Token = NewToken()
	}
	return s.Token
}

// Rotate mints a new token. With a grace, the old token keeps working until
// now+grace so a caller can hand over; with zero grace it stops at once.
// A grace over MaxTokenGrace is refused.
func (s *Session) Rotate(grace time.Duration) error {
	if grace < 0 || grace > MaxTokenGrace {
		return fmt.Errorf("grace %s is outside 0 to 24h", grace)
	}
	old := s.AccessToken()
	if grace == 0 {
		s.PrevToken, s.PrevUntil = "", time.Time{}
	} else {
		s.PrevToken, s.PrevUntil = old, time.Now().Add(grace)
	}
	s.Token = NewToken()
	s.TokenRotatedAt = time.Now()
	return nil
}

// Accepts reports whether tok addresses this session: the current token,
// or the previous one while its grace lasts. Compares in constant time and
// clears an expired grace token on the way.
func (s *Session) Accepts(tok string) bool {
	if tok == "" || s.Token == "" {
		return false
	}
	if subtle.ConstantTimeCompare([]byte(tok), []byte(s.Token)) == 1 {
		return true
	}
	if s.PrevToken == "" {
		return false
	}
	if !time.Now().Before(s.PrevUntil) {
		s.PrevToken, s.PrevUntil = "", time.Time{}
		return false
	}
	return subtle.ConstantTimeCompare([]byte(tok), []byte(s.PrevToken)) == 1
}
```

	ErrNotFound = errors.New("no app of that name is registered")
	nameRe      = regexp.MustCompile(`^[a-z][a-z0-9-]{1,31}$`)
	tiers       = map[string]bool{"query": true, "completions": true}
)

// Budget bounds what one app may ask for: Tokens is the most a reply may be
// asked to produce, PerHour the requests allowed in any sliding hour. Zero
// means unbounded for that limit.
type Budget struct {
	Tokens  int `json:"tokens"`
	PerHour int `json:"per_hour"`
}

// Profile is what an app may do (spec §2.1).
type Profile struct {
	Tiers    []string `json:"tiers"`
	Models   []string `json:"models,omitempty"`
	Packs    []string `json:"packs,omitempty"`
	Sessions string   `json:"sessions"`
	Budget   Budget   `json:"budget"`
}

// App is one registered program.
type App struct {
	Name    string     `json:"name"`
	KeyHash string     `json:"key_hash"`
	Created time.Time  `json:"created"`
	Revoked *time.Time `json:"revoked,omitempty"`
	Profile Profile    `json:"profile"`
}

func (p Profile) AllowsTier(t string) bool {
	for _, x := range p.Tiers {
		if x == t {
			return true
		}
	}
	return false
}

// AllowsModel: "" and "default" are always the serving session's model.
func (p Profile) AllowsModel(m string) bool {
	if m == "" || m == "default" {
		return true
	}
	for _, x := range p.Models {
		if x == m {
			return true
		}
	}
	return false
}

func (p Profile) AllowsPack(name string) bool {
	for _, x := range p.Packs {
		if x == name {
			return true
		}
	}
	return false
}

// Validate refuses a profile the server could not honour.
func (p Profile) Validate() error {
	for _, t := range p.Tiers {
		if !tiers[t] {
			return fmt.Errorf("tier %q is not one of query, completions", t)
		}
	}
	if p.Sessions != "none" && p.Sessions != "named" {
		return fmt.Errorf("sessions %q is not one of none, named", p.Sessions)
	}
	if p.Budget.Tokens < 0 || p.Budget.PerHour < 0 {
		return errors.New("budget values must not be negative")
	}
	return nil
}

// withDefaults is p with the spec's defaults where nothing was given.
func (p Profile) withDefaults() Profile {
	if p.Sessions == "" {
		p.Sessions = "none"
	}
	if p.Budget.Tokens == 0 {
		p.Budget.Tokens = DefaultTokens
	}
	if p.Budget.PerHour == 0 {
		p.Budget.PerHour = DefaultPerHour
	}
	if p.Tiers == nil {
		p.Tiers = []string{}
	}
	return p
}

func ValidName(name string) bool { return nameRe.MatchString(name) }

// NewKey is a fresh app key: the format tag plus 24 random bytes, base64url
// unpadded. Printed once by `apps add`; only its hash is kept.
func NewKey() string {
	var b [24]byte
	if _, err := rand.Read(b[:]); err != nil {
		panic("api: random source failed: " + err.Error())
	}
	return keyPrefix + base64.RawURLEncoding.EncodeToString(b[:])
}

func HashKey(key string) string {
	sum := sha256.Sum256([]byte(key))
	return "sha256:" + hex.EncodeToString(sum[:])
}

// Registry is the app files under Dir, re-read when they change so a
// rotate or revoke from another process takes effect without a restart.
type Registry struct {
	Dir  string
	Warn func(string) // one line per unreadable file, once; nil is silent

	mu     sync.Mutex
	apps   map[string]cachedApp // by file name
	warned map[string]bool
}

type cachedApp struct {
	app   App
	mtime time.Time
	size  int64
	bad   bool
}

func NewRegistry(dir string) *Registry {
	return &Registry{Dir: dir, apps: map[string]cachedApp{}, warned: map[string]bool{}}
}

func (r *Registry) path(name string) string { return filepath.Join(r.Dir, name+".json") }

func (r *Registry) write(a App) error {
	if err := os.MkdirAll(r.Dir, 0o700); err != nil {
		return err
	}
	data, err := json.MarshalIndent(a, "", "  ")
	if err != nil {
		return err
	}
	p := r.path(a.Name)
	tmp := p + ".tmp"
	if err := os.WriteFile(tmp, data, 0o600); err != nil {
		return err
	}
	return os.Rename(tmp, p)
}

// Add registers name with p (defaults filled, validated) and returns the one
// copy of its key that will ever exist.
func (r *Registry) Add(name string, p Profile) (string, error) {
	if !ValidName(name) {
		return "", fmt.Errorf("app name %q must match %s", name, nameRe)
	}
	p = p.withDefaults()
	if err := p.Validate(); err != nil {
		return "", err
	}
	if _, err := os.Stat(r.path(name)); err == nil {
		return "", fmt.Errorf("%w: %s", ErrExists, r.path(name))
	}
	key := NewKey()
	a := App{Name: name, KeyHash: HashKey(key), Created: time.Now(), Profile: p}
	if err := r.write(a); err != nil {
		return "", err
	}
	return key, nil
}

func (r *Registry) Get(name string) (App, error) {
	raw, err := os.ReadFile(r.path(name))
	if errors.Is(err, os.ErrNotExist) {
		return App{}, ErrNotFound
	}
	if err != nil {
		return App{}, err
	}
	var a App
	if err := json.Unmarshal(raw, &a); err != nil {
		return App{}, fmt.Errorf("%s: %w", r.path(name), err)
	}
	return a, nil
}

func (r *Registry) List() ([]App, error) {
	entries, err := os.ReadDir(r.Dir)
	if errors.Is(err, os.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	var out []App
	for _, e := range entries {
		if e.IsDir() || !strings.HasSuffix(e.Name(), ".json") {
			continue
		}
		a, err := r.Get(strings.TrimSuffix(e.Name(), ".json"))
		if err != nil {
			continue
		}
		out = append(out, a)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Name < out[j].Name })
	return out, nil
}

func (r *Registry) Rotate(name string) (string, error) {
	a, err := r.Get(name)
	if err != nil {
		return "", err
	}
	key := NewKey()
	a.KeyHash = HashKey(key)
	a.Revoked = nil
	return key, r.write(a)
}

func (r *Registry) Revoke(name string) error {
	a, err := r.Get(name)
	if err != nil {
		return err
	}
	now := time.Now()
	a.Revoked = &now
	return r.write(a)
}

func (r *Registry) Remove(name string) error {
	err := os.Remove(r.path(name))
	if errors.Is(err, os.ErrNotExist) {
		return ErrNotFound
	}
	return err
}

// Lookup finds the live app whose key this is: constant-time against every
// hash, never a partial match, never a revoked app.
func (r *Registry) Lookup(key string) (App, bool) {
	if !strings.HasPrefix(key, keyPrefix) {
		return App{}, false
	}
	want := []byte(HashKey(key))
	r.mu.Lock()
	defer r.mu.Unlock()
	r.refreshLocked()
	var found App
	ok := false
	for _, c := range r.apps {
		if c.bad {
			continue
		}
		// Every candidate is compared so timing does not say which exists.
		if subtle.ConstantTimeCompare([]byte(c.app.KeyHash), want) == 1 && c.app.Revoked == nil {
			found, ok = c.app, true
		}
	}
	return found, ok
}

// refreshLocked re-reads any file whose mtime or size changed and forgets
// files that are gone.
func (r *Registry) refreshLocked() {
	entries, err := os.ReadDir(r.Dir)
	if err != nil {
		r.apps = map[string]cachedApp{}
		return
	}
	seen := map[string]bool{}
	for _, e := range entries {
		if e.IsDir() || !strings.HasSuffix(e.Name(), ".json") {
			continue
		}
		info, err := e.Info()
		if err != nil {
			continue
		}
		seen[e.Name()] = true
		if c, ok := r.apps[e.Name()]; ok && c.mtime.Equal(info.ModTime()) && c.size == info.Size() {
			continue
		}
		raw, err := os.ReadFile(filepath.Join(r.Dir, e.Name()))
		var a App
		if err == nil {
			err = json.Unmarshal(raw, &a)
		}
		if err != nil || a.KeyHash == "" {
			if !r.warned[e.Name()] {
				r.warned[e.Name()] = true
				if r.Warn != nil {
					r.Warn(fmt.Sprintf("api: app file %s could not be read and is ignored: %v", filepath.Join(r.Dir, e.Name()), err))
				}
			}
			r.apps[e.Name()] = cachedApp{mtime: info.ModTime(), size: info.Size(), bad: true}
			continue
		}
		r.apps[e.Name()] = cachedApp{app: a, mtime: info.ModTime(), size: info.Size()}
	}
	for name := range r.apps {
		if !seen[name] {
			delete(r.apps, name)
		}
	}
}

package api

import (
	"sync"
	"time"
)

// budgets is the per-app rate limit (a sliding hour of request times) and
// the one-in-flight rule. In memory only: a restart resets it, which is
// fine for a rate limit.
type budgets struct {
	now      func() time.Time
	mu       sync.Mutex
	times    map[string][]time.Time
	inflight map[string]bool
}

func newBudgets(now func() time.Time) *budgets {
	return &budgets{now: now, times: map[string][]time.Time{}, inflight: map[string]bool{}}
}

// take records one request for app against perHour. When refused it says
// how long until the oldest request leaves the window.
func (b *budgets) take(app string, perHour int) (retryAfter time.Duration, ok bool) {
	if perHour <= 0 {
		return 0, true
	}
	b.mu.Lock()
	defer b.mu.Unlock()
	now := b.now()
	cut := now.Add(-time.Hour)
	ts := b.times[app]
	i := 0
	for i < len(ts) && !ts[i].After(cut) {
		i++
	}
	ts = ts[i:]
	if len(ts) >= perHour {
		b.times[app] = ts
		return ts[0].Add(time.Hour).Sub(now), false
	}
	b.times[app] = append(ts, now)
	return 0, true
}

// begin claims the app's one in-flight slot; release gives it back.
func (b *budgets) begin(app string) (release func(), ok bool) {
	b.mu.Lock()
	defer b.mu.Unlock()
	if b.inflight[app] {
		return nil, false
	}
	b.inflight[app] = true
	var once sync.Once
	return func() {
		once.Do(func() {
			b.mu.Lock()
			delete(b.inflight, app)
			b.mu.Unlock()
		})
	}, true
}

// implemented over the running agent in internal/agent (APIBackend) and by
// a fake in this package's tests. Nothing here may change the session: a
// query is answered, never appended.
type Backend interface {
	Health() Health
	Query(ctx context.Context, q QueryRequest) (QueryResponse, error)
	Complete(ctx context.Context, c CompletionRequest, onDelta func(string)) (CompletionResponse, error)
	SessionInfo() SessionInfo
	AcceptsSession(token string) bool
	SessionQuery(ctx context.Context, q QueryRequest) (QueryResponse, error)

type Health struct {
	Version     string
	SessionCode string
	Model       string
	Since       time.Time
}

type SessionInfo struct{ Title, Workspace, Model string }

type Usage struct {
	PromptTokens     int `json:"prompt_tokens"`
	CompletionTokens int `json:"completion_tokens"`
}

// QueryRequest is one tool-less question (spec §4.1). Model "" or "default"
// is the serving session's model. Pack names a pack whose core rules go in
// front of System; JSONSchema, when set, is the structured-output format.
type QueryRequest struct {
	Prompt     string
	System     string
	Model      string
	Pack       string
	JSONSchema json.RawMessage
	MaxTokens  int
}

type QueryResponse struct {
	Text  string
	Model string
	Pack  *string // the pack used, nil when none or it went inactive
	Usage Usage
}

type ChatMessage struct {
	Role    string
	Content string
}

// CompletionRequest is the OpenAI chat-completions request reduced to what
// the backend needs (spec §4.2).
type CompletionRequest struct {
	Model          string
	Messages       []ChatMessage
	Temperature    *float64
	MaxTokens      int
	ResponseFormat json.RawMessage
}

type CompletionResponse struct {
	Text         string
	Model        string
	FinishReason string
	Usage        Usage
}

// Error is a failure the backend wants reported with a particular status
// and code. Any other error from a Backend is 502 backend_error.
type Error struct {
	Status  int
	Code    string
	Message string
	Extra   map[string]any // merged into the error object (e.g. "text" for schema_mismatch)
}

func (e *Error) Error() string { return e.Code + ": " + e.Message }

func Errorf(status int, code, format string, args ...any) *Error {
	return &Error{Status: status, Code: code, Message: fmt.Sprintf(format, args...)}
}

// writeError sends the spec's error body: {"error": {"code", "message", ...}}.
func writeError(w http.ResponseWriter, e *Error) {
	body := map[string]any{"code": e.Code, "message": e.Message}
	for k, v := range e.Extra {
		body[k] = v
	}
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(e.Status)
	_ = json.NewEncoder(w).Encode(map[string]any{"error": body})
}

// toError maps any backend error to an *Error. A context deadline is the
// request's own timeout; a cancellation is the client gone.
func toError(err error) *Error {
	if e, ok := err.(*Error); ok {
		return e
	}
	if err == context.DeadlineExceeded {
		return Errorf(http.StatusGatewayTimeout, "timeout", "the request did not finish within api.timeout")
	}
	return Errorf(http.StatusBadGateway, "backend_error", "%v", err)
}

// Handler is the whole API as an http.Handler (tests mount it on httptest).
func (s *Server) Handler() http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		// Browser refusal before anything else — and before the body is
		// touched: a page in the person's browser can reach loopback.
		if r.Header.Get("Origin") != "" || r.Header.Get("Sec-Fetch-Mode") != "" {
			writeError(w, Errorf(http.StatusForbidden, "browser_refused", "this API is for programs, not pages"))
			return
		}
		if s.closing.Load() {
			writeError(w, Errorf(http.StatusServiceUnavailable, "shutting_down", "the serving session is ending"))
			return
		}
		r.Body = http.MaxBytesReader(w, r.Body, maxBody)
		s.mux.ServeHTTP(w, r)
	})
}

func (s *Server) Serve(l net.Listener) error { return s.http.Serve(l) }

// Close refuses new requests, answers in-flight ones 503 by cancelling
// their contexts, and shuts the listener.
func (s *Server) Close(ctx context.Context) error {
	s.closing.Store(true)
	return s.http.Shutdown(ctx)
}

// serve is the check order of spec §2.4 steps 2–8 and the access log.
func (s *Server) serve(w http.ResponseWriter, r *http.Request, template, tier string, session bool, h handler) {
	start := s.o.Now()
	c := &call{w: w, r: r, route: template}
	status := &statusWriter{ResponseWriter: w, status: 200}
	c.w = status
	defer func() {
		s.logLine(c, status.status, s.o.Now().Sub(start))
	}()

	if s.lockedOut() {
		writeError(c.w, Errorf(http.StatusTooManyRequests, "rate_limited", "too many failed authentications; try again in a minute"))
		return
	}
	app, ok := s.authenticate(r)
	if !ok {
		s.failed(c.w, Errorf(http.StatusUnauthorized, "unauthorized", "unknown, revoked or malformed app key"))
		return
	}
	c.app = app
	if tier != "" && !app.Profile.AllowsTier(tier) {
		writeError(c.w, Errorf(http.StatusForbidden, "tier_not_allowed", "app %q may not call the %s tier", app.Name, tier))
		return
	}
	hdrTok := r.Header.Get("X-BE-Session")
	if hdrTok != "" && app.Profile.Sessions != "named" {
		writeError(c.w, Errorf(http.StatusForbidden, "sessions_not_allowed", "app %q may not address a session", app.Name))
		return
	}
	if session {
		pathTok := r.PathValue("token")
		if hdrTok != "" && hdrTok != pathTok {
			writeError(c.w, Errorf(http.StatusBadRequest, "session_mismatch", "the session in the path and in X-BE-Session differ"))
			return
		}
		if app.Profile.Sessions != "named" {
			writeError(c.w, Errorf(http.StatusForbidden, "sessions_not_allowed", "app %q may not address a session", app.Name))
			return
		}
		if !s.o.Backend.AcceptsSession(pathTok) {
			s.failed(c.w, Errorf(http.StatusNotFound, "session_not_found", "no such session"))
			return
		}
		c.sessionToken = pathTok
		c.sessionCode = s.o.Backend.Health().SessionCode
	}
	if retry, ok := s.budgets.take(app.Name, app.Profile.Budget.PerHour); !ok {
		c.w.Header().Set("Retry-After", strconv.Itoa(int(retry.Seconds())+1))
		writeError(c.w, Errorf(http.StatusTooManyRequests, "rate_limited", "app %q is over its %d requests per hour", app.Name, app.Profile.Budget.PerHour))
		return
	}
	release, ok := s.budgets.begin(app.Name)
	if !ok {
		c.w.Header().Set("Retry-After", "1")
		writeError(c.w, Errorf(http.StatusTooManyRequests, "rate_limited", "app %q already has a request in flight", app.Name))
		return
	}
	defer release()
	ctx, cancel := context.WithTimeout(r.Context(), s.o.Timeout)
	defer cancel()
	c.r = r.WithContext(ctx)
	h(s, c)
	s.statsMu.Lock()
	s.stats.Served++
	s.stats.LastApp, s.stats.LastAt = app.Name, s.o.Now()
	s.statsMu.Unlock()
}

// authenticate: Bearer with the key prefix, well-formed, hashed and found.
func (s *Server) authenticate(r *http.Request) (App, bool) {
	auth := r.Header.Get("Authorization")
	key, ok := strings.CutPrefix(auth, "Bearer ")
	if !ok || !strings.HasPrefix(key, keyPrefix) {
		return App{}, false
	}
	raw, err := base64.RawURLEncoding.DecodeString(strings.TrimPrefix(key, keyPrefix))
	if err != nil || len(raw) != 24 {
		return App{}, false
	}
	return s.o.Apps.Lookup(key)
}

// failed answers a 401 or 404 after the delay, closing the connection, and
// counts it toward the lockout.
func (s *Server) failed(w http.ResponseWriter, e *Error) {
	s.failMu.Lock()
	now := s.o.Now()
	if now.Sub(s.failWindow) >= time.Minute {
		s.failWindow, s.failures = now, 0
	}
	s.failures++
	s.failMu.Unlock()
	s.o.Sleep(failureDelay)
	w.Header().Set("Connection", "close")
	writeError(w, e)
}

func (s *Server) lockedOut() bool {
	s.failMu.Lock()
	defer s.failMu.Unlock()
	if s.o.Now().Sub(s.failWindow) >= time.Minute {
		return false
	}
	return s.failures >= failureLockout
}

}

A deliberately small subset: `type` (string, integer, number, boolean, object, array, null), `properties`, `required`, `items`, `enum`, `additionalProperties: false`. Anything else in the schema is ignored, and the file says so.

```go
package api

import (
	"encoding/json"
	"fmt"
	"math"
	"reflect"
)

// Validate checks doc against the JSON-schema subset this build understands:
// type, properties, required, items, enum and additionalProperties:false.
// Other keywords are ignored, so a schema using them is checked loosely,
// never refused. The point is to tell a caller "the model did not produce
// what you asked for" rather than to be a full validator.
func Validate(schema json.RawMessage, doc []byte) error {
	var sc map[string]any
	if err := json.Unmarshal(schema, &sc); err != nil {
		return fmt.Errorf("json_schema is not a JSON object: %w", err)
	}
	var v any
	if err := json.Unmarshal(doc, &v); err != nil {
		return fmt.Errorf("the reply is not JSON: %w", err)
	}
	return validate(sc, v, "$")
}

func validate(sc map[string]any, v any, at string) error {
	if t, ok := sc["type"].(string); ok {
		if err := checkType(t, v, at); err != nil {
			return err
		}
	}
	if enum, ok := sc["enum"].([]any); ok {
		found := false
		for _, e := range enum {
			if reflect.DeepEqual(e, v) {
				found = true
				break
			}
		}
		if !found {
			return fmt.Errorf("%s: %v is not one of the enum values", at, v)
		}
	}
	if obj, ok := v.(map[string]any); ok {
		if req, ok := sc["required"].([]any); ok {
			for _, r := range req {
				if name, _ := r.(string); name != "" {
					if _, has := obj[name]; !has {
						return fmt.Errorf("%s: missing required property %q", at, name)
					}
				}
			}
		}
		props, _ := sc["properties"].(map[string]any)
		for name, val := range obj {
			ps, has := props[name].(map[string]any)
			if !has {
				if ap, ok := sc["additionalProperties"].(bool); ok && !ap {
					return fmt.Errorf("%s: property %q is not allowed", at, name)
				}
				continue
			}
			if err := validate(ps, val, at+"."+name); err != nil {
				return err
			}
		}
	}
	if arr, ok := v.([]any); ok {
		if items, ok := sc["items"].(map[string]any); ok {
			for i, e := range arr {
				if err := validate(items, e, fmt.Sprintf("%s[%d]", at, i)); err != nil {
					return err
				}
			}
		}
	}
	return nil
}

func checkType(t string, v any, at string) error {
	ok := false
	switch t {
	case "string":
		_, ok = v.(string)
	case "boolean":
		_, ok = v.(bool)
	case "object":
		_, ok = v.(map[string]any)
	case "array":
		_, ok = v.([]any)
	case "null":
		ok = v == nil
	case "number":
		_, ok = v.(float64)
	case "integer":
		f, is := v.(float64)
		ok = is && f == math.Trunc(f)
	default:
		return fmt.Errorf("%s: schema type %q is not understood", at, t)
	}
	if !ok {
		return fmt.Errorf("%s: want %s, got %T", at, t, v)
	}
	return nil
}

	"net/http"

type queryBody struct {
	Prompt     string          `json:"prompt"`
	System     string          `json:"system"`
	Model      string          `json:"model"`
	Pack       string          `json:"pack"`
	JSONSchema json.RawMessage `json:"json_schema"`
	MaxTokens  int             `json:"max_tokens"`
}

func (b queryBody) request() QueryRequest {
	return QueryRequest{Prompt: b.Prompt, System: b.System, Model: b.Model, Pack: b.Pack, JSONSchema: b.JSONSchema, MaxTokens: b.MaxTokens}
}

// checkQuery applies spec §2.4 steps 7 and 8's request-level checks and
// fills the max_tokens default from the app's budget.
func checkQuery(s *Server, c *call, q *QueryRequest) bool {
	if q.Prompt == "" {
		writeError(c.w, Errorf(http.StatusBadRequest, "bad_request", "prompt is required"))
		return false
	}
	if !c.app.Profile.AllowsModel(q.Model) {
		writeError(c.w, Errorf(http.StatusForbidden, "model_not_allowed", "app %q may not use model %q", c.app.Name, q.Model))
		return false
	}
	if q.Pack != "" && (!c.app.Profile.AllowsPack(q.Pack) || !s.o.Backend.PackActive(q.Pack)) {
		writeError(c.w, Errorf(http.StatusForbidden, "pack_not_allowed", "pack %q is not in app %q's profile or not active in the serving session", q.Pack, c.app.Name))
		return false
	}
	cap := c.app.Profile.Budget.Tokens
	if q.MaxTokens == 0 {
		q.MaxTokens = cap
	}
	if cap > 0 && q.MaxTokens > cap {
		writeError(c.w, Errorf(http.StatusBadRequest, "over_budget", "max_tokens %d is over app %q's budget of %d", q.MaxTokens, c.app.Name, cap))
		return false
	}
	return true
}

// answerQuery runs one query through the given backend method and writes
// the reply, checking it against json_schema when one was given.
func answerQuery(s *Server, c *call, q QueryRequest, run func() (QueryResponse, error)) {
	resp, err := run()
	if err != nil {
		writeError(c.w, s.mapErr(err))
		return
	}
	if len(q.JSONSchema) > 0 {
		if verr := Validate(q.JSONSchema, []byte(resp.Text)); verr != nil {
			e := Errorf(http.StatusUnprocessableEntity, "schema_mismatch", "the reply does not match json_schema: %v", verr)
			e.Extra = map[string]any{"text": resp.Text}
			writeError(c.w, e)
			return
		}
	}
	writeJSON(c, map[string]any{"text": resp.Text, "model": resp.Model, "pack": resp.Pack, "usage": resp.Usage})
}

func handleQuery(s *Server, c *call) {
	var b queryBody
	if !readJSON(c, &b) {
		return
	}
	q := b.request()
	if !checkQuery(s, c, &q) {
		return
	}
	answerQuery(s, c, q, func() (QueryResponse, error) { return s.o.Backend.Query(c.r.Context(), q) })
}

func handleSessionQuery(s *Server, c *call) {
	var b queryBody
	if !readJSON(c, &b) {
		return
	}
	q := b.request()
	if !checkQuery(s, c, &q) {
		return
	}
	answerQuery(s, c, q, func() (QueryResponse, error) { return s.o.Backend.SessionQuery(c.r.Context(), q) })
}

func handleSessionInfo(s *Server, c *call) {
	i := s.o.Backend.SessionInfo()
	writeJSON(c, map[string]any{"title": i.Title, "workspace": i.Workspace, "model": i.Model, "live": true})

}

// parseCompletion turns the wire request into a backend request or a 400.
func parseCompletion(c *call, in chatCompletionRequest) (CompletionRequest, *Error) {
	for name, raw := range map[string]json.RawMessage{"tools": in.Tools, "functions": in.Functions, "tool_choice": in.ToolChoice} {
		if len(raw) > 0 && string(raw) != "null" {
			return CompletionRequest{}, Errorf(http.StatusBadRequest, "not_supported", "%s is not supported: this API serves inference without tools", name)
		}
	}
	if in.N != nil && *in.N > 1 {
		return CompletionRequest{}, Errorf(http.StatusBadRequest, "not_supported", "n above 1 is not supported")
	}
	if len(in.Messages) == 0 {
		return CompletionRequest{}, Errorf(http.StatusBadRequest, "not_supported", "messages must have at least one message")
	}
	out := CompletionRequest{Model: in.Model, Temperature: in.Temperature, MaxTokens: in.MaxTokens, ResponseFormat: in.ResponseFormat}
	for i, raw := range in.Messages {
		var m wireMessage
		if err := json.Unmarshal(raw, &m); err != nil {
			return CompletionRequest{}, Errorf(http.StatusBadRequest, "bad_request", "messages[%d] is not an object: %v", i, err)
		}
		switch m.Role {
		case "system", "user", "assistant":
		default:
			return CompletionRequest{}, Errorf(http.StatusBadRequest, "not_supported", "messages[%d]: role %q is not supported (system, user, assistant)", i, m.Role)
		}
		var text string
		if err := json.Unmarshal(m.Content, &text); err != nil {
			return CompletionRequest{}, Errorf(http.StatusBadRequest, "not_supported", "messages[%d]: content must be a string; content parts are not supported", i)
		}
		out.Messages = append(out.Messages, ChatMessage{Role: m.Role, Content: text})
	}
	if !c.app.Profile.AllowsModel(out.Model) {
		return CompletionRequest{}, Errorf(http.StatusForbidden, "model_not_allowed", "app %q may not use model %q", c.app.Name, out.Model)
	}
	cap := c.app.Profile.Budget.Tokens
	if out.MaxTokens == 0 {
		out.MaxTokens = cap
	}
	if cap > 0 && out.MaxTokens > cap {
		return CompletionRequest{}, Errorf(http.StatusBadRequest, "over_budget", "max_tokens %d is over app %q's budget of %d", out.MaxTokens, c.app.Name, cap)
	}
	return out, nil
}

func handleCompletions(s *Server, c *call) {
	var in chatCompletionRequest
	if !readJSON(c, &in) {
		return
	}
	req, e := parseCompletion(c, in)
	if e != nil {
		writeError(c.w, e)
		return
	}
	id, created := completionID(), time.Now().Unix()
	if !in.Stream {
		resp, err := s.o.Backend.Complete(c.r.Context(), req, nil)
		if err != nil {
			writeError(c.w, s.mapErr(err))
			return
		}
		fr := resp.FinishReason
		writeJSON(c, chatCompletionResponse{
			ID: id, Object: "chat.completion", Created: created, Model: resp.Model,
			Choices: []chatChoice{{Message: &wireContent{Role: "assistant", Content: resp.Text}, FinishReason: &fr}},
			Usage:   wireUsage{resp.Usage.PromptTokens, resp.Usage.CompletionTokens, resp.Usage.PromptTokens + resp.Usage.CompletionTokens},
		})
		return
	}

	// Streaming: headers first, then one chunk per delta, then the finish
	// chunk and [DONE]. An error before the first delta is still a JSON
	// error; after it, the stream ends without [DONE], which is how the
	// OpenAI clients report a broken stream.
	flusher, _ := c.w.(http.Flusher)
	started := false
	send := func(v any) {
		if !started {
			c.w.Header().Set("Content-Type", "text/event-stream")
			c.w.Header().Set("Cache-Control", "no-cache")
			c.w.WriteHeader(http.StatusOK)
			started = true
		}
		b, _ := json.Marshal(v)
		fmt.Fprintf(c.w, "data: %s\n\n", b)
		if flusher != nil {
			flusher.Flush()
		}
	}
	chunk := func(delta *wireContent, finish *string) chatChunk {
		return chatChunk{ID: id, Object: "chat.completion.chunk", Created: created, Model: req.Model, Choices: []chatChoice{{Delta: delta, FinishReason: finish}}}
	}
	resp, err := s.o.Backend.Complete(c.r.Context(), req, func(delta string) {
		send(chunk(&wireContent{Role: "assistant", Content: delta}, nil))
	})
	if err != nil {
		if !started {
			writeError(c.w, s.mapErr(err))
		}
		return
	}
	fr := resp.FinishReason
	send(chunk(&wireContent{}, &fr))
	fmt.Fprint(c.w, "data: [DONE]\n\n")
	if flusher != nil {
		flusher.Flush()
	}
}
```

The model name in a chunk is the resolved name only once the backend answers; chunks carry the requested name (`req.Model`, or `default`). Document that in the README's API section rather than buffering the stream to learn it.

package api

import (
	"encoding/json"
	"errors"
	"fmt"
	"net"
	"os"

	"runtime"
	"time"

	"github.com/brown-enterprises/be-code/internal/procattr"

// Record advertises the serving session, like a live record: who to name
// when a second session finds the socket taken, and what /api and doctor
// report. Pruned when its pid is gone.
type Record struct {
	PID         int       `json:"pid"`
	Socket      string    `json:"socket"`
	SessionCode string    `json:"session_code"`
	Started     time.Time `json:"started"`
}

var ErrServedElsewhere = errors.New("the API is served by another session")

// ServedElsewhere is Listen's answer when a live session already serves.
type ServedElsewhere struct{ Record Record }

func (e *ServedElsewhere) Error() string {
	return fmt.Sprintf("API is served by session %s (pid %d); this session is not serving", e.Record.SessionCode, e.Record.PID)
}
func (e *ServedElsewhere) Is(target error) bool { return target == ErrServedElsewhere }

// Dir is ~/.be-code/api.
func Dir() (string, error) {
	home, err := os.UserHomeDir()
	if err != nil {
		return "", err
	}
	return filepath.Join(home, ".be-code", "api"), nil
}

func SocketPath(dir string) string { return filepath.Join(dir, "api.sock") }
func recordPath(dir string) string { return filepath.Join(dir, "server.json") }

// CheckDir refuses to serve from a directory other users could read: the
// socket's mode is the whole boundary on Unix. Windows does not enforce
// modes on these paths, so the check is skipped there.
func CheckDir(dir string) error {
	if runtime.GOOS == "windows" {
		return nil
	}
	for _, d := range []string{dir, filepath.Join(dir, "apps")} {
		st, err := os.Stat(d)
		if errors.Is(err, os.ErrNotExist) {
			continue
		}
		if err != nil {
			return err
		}
		if st.Mode().Perm()&0o077 != 0 {
			return fmt.Errorf("api: %s is mode %04o; fix with chmod 700 %s", d, st.Mode().Perm(), d)
		}
	}
	return nil
}

// Serving is the live record, if any: a record whose pid is gone is pruned
// and reported as nobody.
func Serving(dir string) (Record, bool) {
	raw, err := os.ReadFile(recordPath(dir))
	if err != nil {
		return Record{}, false
	}
	var r Record
	if json.Unmarshal(raw, &r) != nil || r.PID <= 0 || !procattr.Alive(r.PID) {
		_ = os.Remove(recordPath(dir))
		return Record{}, false
	}
	return r, true
}

// Listen binds the socket. On address-in-use it connects: a refusal means
// a stale socket, removed and re-bound; a live listener means another
// session serves and the error names it from its record.
func Listen(dir string, rec Record) (net.Listener, error) {
	if err := os.MkdirAll(filepath.Join(dir, "apps"), 0o700); err != nil {
		return nil, err
	}
	if err := CheckDir(dir); err != nil {
		return nil, err
	}
	path := SocketPath(dir)
	l, err := net.Listen("unix", path)
	if err != nil {
		if c, derr := net.DialTimeout("unix", path, time.Second); derr == nil {
			c.Close()
			r, _ := Serving(dir)
			if r.SessionCode == "" {
				r = Record{Socket: path}
			}
			return nil, &ServedElsewhere{Record: r}
		}
		_ = os.Remove(path)
		_ = os.Remove(recordPath(dir))
		if l, err = net.Listen("unix", path); err != nil {
			return nil, err
		}
	}
	if runtime.GOOS != "windows" {
		_ = os.Chmod(path, 0o600)
	}
	rec.Socket = path
	if rec.Started.IsZero() {
		rec.Started = time.Now()
	}
	data, _ := json.MarshalIndent(rec, "", "  ")
	if err := os.WriteFile(recordPath(dir), data, 0o600); err != nil {
		l.Close()
		return nil, err
	}
	return l, nil
}

// Release removes this process's socket and record. Another process's
// record is left alone.
func Release(dir string) {
	if r, ok := Serving(dir); ok && r.PID != os.Getpid() {
		return
	}
	_ = os.Remove(SocketPath(dir))
	_ = os.Remove(recordPath(dir))
}
```

Note: Go's unix `net.Listener.Close` unlinks the socket file itself; `Release` is for the record and for the crash-recovery path where `Close` never ran.

// APIModelFactory builds a provider for a model the serving session is not
// running, loaded as a reviewer is (cmd/root.go: FromConfig + secondaryLoad)
// so the primary's window is never touched. Nil means only "default" is
// served. Injected from cmd/root.go like ReviewerFactory.
var APIModelFactory func(ctx context.Context, cfg *config.Config, model string) (provider.Provider, error)

// APIBackend answers the application API from the running session (spec
// 2026-11-02-app-api-design.md §4–§5). Nothing here is a typed request: it
// never clears UntrustedWeb, never touches the inbox, the engine, the work
// ledger or History.Messages, and never writes.
type APIBackend struct {
	a       *Agent
	version string
	since   time.Time

	mu    sync.Mutex
	provs map[string]provider.Provider // named models, built once each
}

func NewAPIBackend(a *Agent, version string) *APIBackend {
	return &APIBackend{a: a, version: version, since: time.Now(), provs: map[string]provider.Provider{}}
}

func (b *APIBackend) Health() api.Health {
	code := ""
	if b.a.Session != nil {
		code = b.a.Session.ResumeCode()
	}
	return api.Health{Version: b.version, SessionCode: code, Model: b.a.Model, Since: b.since}
}

func (b *APIBackend) SessionInfo() api.SessionInfo {
	title := ""
	if b.a.Session != nil {
		title = b.a.Session.Title
	}
	return api.SessionInfo{Title: title, Workspace: b.a.Tools.Root, Model: b.a.Model}
}

// AcceptsSession compares under saveMu: Accepts may clear an expired grace
// token, and autosave marshals the same struct.
func (b *APIBackend) AcceptsSession(tok string) bool {
	if b.a.Session == nil {
		return false
	}
	b.a.saveMu.Lock()
	defer b.a.saveMu.Unlock()
	return b.a.Session.Accepts(tok)
}

func (b *APIBackend) PackActive(name string) bool { return b.activePack(name) != nil }

func (b *APIBackend) activePack(name string) *packs.Pack {
	for _, src := range b.a.Tools.Packs() {
		if p, ok := src.(*packs.Pack); ok && p.Name == name {
			return p
		}
	}
	return nil
}

// Query is one tool-less chat with no history (spec §4.1).
func (b *APIBackend) Query(ctx context.Context, q api.QueryRequest) (api.QueryResponse, error) {
	system, used := b.systemFor(q)
	msgs := []provider.Message{}
	if system != "" {
		msgs = append(msgs, provider.Message{Role: provider.RoleSystem, Content: system})
	}
	msgs = append(msgs, provider.Message{Role: provider.RoleUser, Content: q.Prompt})
	resp, model, err := b.chat(ctx, q.Model, provider.ChatRequest{Messages: msgs, MaxTokens: q.MaxTokens, NoThink: true}, nil)
	if err != nil {
		return api.QueryResponse{}, err
	}
	return api.QueryResponse{Text: strings.TrimSpace(resp.Content), Model: model, Pack: used, Usage: usageOf(resp)}, nil
}

// systemFor is the caller's system text with an allowed, active pack's
// rules in front; used names the pack, or is nil when none or it went
// inactive between the server's check and this call.
func (b *APIBackend) systemFor(q api.QueryRequest) (string, *string) {
	if q.Pack == "" {
		return q.System, nil
	}
	p := b.activePack(q.Pack)
	if p == nil {
		return q.System, nil
	}
	name := p.Name
	rules := packBlock(p)
	if q.System == "" {
		return rules, &name
	}
	return rules + "\n\n" + q.System, &name
}

// Complete is the chat-completions tier: the caller's messages as they are.
func (b *APIBackend) Complete(ctx context.Context, c api.CompletionRequest, onDelta func(string)) (api.CompletionResponse, error) {
	msgs := make([]provider.Message, 0, len(c.Messages))
	for _, m := range c.Messages {
		msgs = append(msgs, provider.Message{Role: provider.Role(m.Role), Content: m.Content})
	}
	req := provider.ChatRequest{Messages: msgs, MaxTokens: c.MaxTokens, NoThink: true}
	if c.Temperature != nil {
		req.Temperature = *c.Temperature
	}
	var stream provider.StreamFunc
	if onDelta != nil {
		stream = func(d string) { onDelta(d) }
	}
	resp, model, err := b.chat(ctx, c.Model, req, stream)
	if err != nil {
		return api.CompletionResponse{}, err
	}
	fr := resp.FinishReason
	if fr == "" {
		fr = "stop"
	}
	return api.CompletionResponse{Text: resp.Content, Model: model, FinishReason: fr, Usage: usageOf(resp)}, nil
}

// SessionQuery answers with a snapshot of the session's conversation as
// context (spec §4.3): taken only when no turn is running, harness state
// stripped, web page text withheld, never appended.
func (b *APIBackend) SessionQuery(ctx context.Context, q api.QueryRequest) (api.QueryResponse, error) {
	a := b.a
	if !a.turnMu.TryLock() {
		return api.QueryResponse{}, api.Errorf(http.StatusConflict, "session_busy", "the session is in the middle of a turn; try again shortly")
	}
	system := a.History.System.Content
	snapshot := make([]provider.Message, 0, len(a.History.Messages)+1)
	all := a.History.Messages
	for _, m := range all {
		m := m
		if webResult(m, all) {
			m.Content = "(page text is not shown)"
		} else {
			m.Content = StripHarnessState(m.Content)
		}
		snapshot = append(snapshot, m)
	}
	a.turnMu.Unlock()

	callerSystem, used := b.systemFor(q)
	if callerSystem != "" {
		system = strings.TrimSpace(system + "\n\n" + callerSystem)
	}
	msgs := []provider.Message{{Role: provider.RoleSystem, Content: system}}
	msgs = append(msgs, snapshot...)
	msgs = append(msgs, provider.Message{Role: provider.RoleUser, Content: q.Prompt})

	if w := a.Window(); w > 0 {
		need := q.MaxTokens
		for _, m := range msgs {
			need += a.History.MessageTokens(m)
		}
		if need > w {
			return api.QueryResponse{}, api.Errorf(http.StatusRequestEntityTooLarge, "context_too_large",
				"the session's conversation plus the prompt and max_tokens need about %d tokens; the window is %d", need, w)
		}
	}
	resp, model, err := b.chat(ctx, q.Model, provider.ChatRequest{Messages: msgs, MaxTokens: q.MaxTokens, NoThink: true}, nil)
	if err != nil {
		return api.QueryResponse{}, err
	}
	return api.QueryResponse{Text: strings.TrimSpace(resp.Content), Model: model, Pack: used, Usage: usageOf(resp)}, nil
}

// chat runs one request inside the server's lane on the primary's own
// provider (model "" or "default") or on a named model's provider built by
// APIModelFactory. It deliberately does not go through chatFiltered: that
// streams into Events.OnDelta, the person's transcript, and an app's answer
// is not the person's conversation. What it keeps from chatFiltered: the
// spend check and accounting, think-stripping, and stats. Afterwards, with
// the primary idle, the person's prompt is re-read in the background (spec
// §5: the API call made the cache cold).
func (b *APIBackend) chat(ctx context.Context, model string, req provider.ChatRequest, onDelta provider.StreamFunc) (*provider.ChatResponse, string, error) {
	a := b.a
	if err := a.checkSpendCap(ctx); err != nil {
		return nil, "", api.Errorf(http.StatusTooManyRequests, "spend_cap", "%v", err)
	}
	prov, name := a.Provider, a.Model
	primary := model == "" || model == "default"
	if !primary {
		p, err := b.providerFor(ctx, model)
		if err != nil {
			return nil, "", err
		}
		prov, name = p, model
	}
	req.Model = name
	if a.Profile.StripThink && onDelta != nil {
		f := &ThinkFilter{}
		inner := onDelta
		onDelta = func(d string) {
			if out := f.Feed(d); out != "" {
				inner(out)
			}
		}
		defer func() {
			if tail := f.Flush(); tail != "" {
				inner(tail)
			}
		}()
	}
	resp, err := a.inLane(ctx, func() (*provider.ChatResponse, error) { return prov.Chat(ctx, req, onDelta) })
	if err != nil {
		return nil, "", err
	}
	if a.Profile.StripThink {
		resp.Content = StripThink(resp.Content)
	}
	used := Stats{Requests: 1, PromptTokens: resp.Usage.PromptTokens, CompletionTokens: resp.Usage.CompletionTokens}
	if used.PromptTokens == 0 {
		for _, m := range req.Messages {
			used.PromptTokens += a.History.MessageTokens(m)
		}
		used.CompletionTokens = a.History.est(resp.Content)
	}
	if _, online := a.Online(); online && primary {
		if p := a.Pricing(); p.Known {
			used.SpendUSD = float64(used.PromptTokens)*p.Prompt + float64(used.CompletionTokens)*p.Completion
		}
	}
	a.addStats(used)
	if primary {
		a.StartPrefill()
	}
	return resp, name, nil
}

func (b *APIBackend) providerFor(ctx context.Context, model string) (provider.Provider, error) {
	b.mu.Lock()
	defer b.mu.Unlock()
	if p, ok := b.provs[model]; ok {
		return p, nil
	}
	if APIModelFactory == nil {
		return nil, api.Errorf(http.StatusForbidden, "model_not_allowed", "this session serves only its own model")
	}
	p, err := APIModelFactory(ctx, b.a.Cfg, model)
	if err != nil {
		return nil, fmt.Errorf("model %s: %w", model, err)
	}
	b.provs[model] = p
	return p, nil
}

func usageOf(r *provider.ChatResponse) api.Usage {
	return api.Usage{PromptTokens: r.Usage.PromptTokens, CompletionTokens: r.Usage.CompletionTokens}
}

// SessionToken is the session's token, minted and saved if it had none.
func (a *Agent) SessionToken() (string, error) {
	if a.Session == nil {
		return "", errors.New("no session")
	}
	a.saveMu.Lock()
	tok := a.Session.AccessToken()
	a.saveMu.Unlock()
	return tok, a.saveSessionNow()
}

// RotateSessionToken replaces the token (spec §3.1) and saves.
func (a *Agent) RotateSessionToken(grace time.Duration) (string, error) {
	if a.Session == nil {
		return "", errors.New("no session")
	}
	a.saveMu.Lock()
	err := a.Session.Rotate(grace)
	tok := a.Session.Token
	a.saveMu.Unlock()
	if err != nil {
		return "", err
	}
	return tok, a.saveSessionNow()
}

// saveSessionNow persists the session's fields as autosave does, without a
// user input to title it from. Refused when another host owns the file.
func (a *Agent) saveSessionNow() error {
	if blocked, owner := a.SaveGuard(); blocked {
		return fmt.Errorf("session file is owned by live host %d", owner)
	}
	a.saveMu.Lock()
	defer a.saveMu.Unlock()
	a.Session.Model = a.Model
	a.Session.Messages = a.History.Messages
	return a.Session.Save()
}

// apiService is the application API as one interactive session serves it:
// built in buildAgent, started by a UI once approvals are wired (like
// StartSchedules), stopped first in finishSession. It implements
// agent.APIControl for /api on|off and the header.
type apiService struct {
	cfg *config.Config
	ag  *agent.Agent
	dir string

	mu     sync.Mutex
	srv    *api.Server
	ln     net.Listener
	status agent.APIStatus
}

func buildAPI(cfg *config.Config, ag *agent.Agent) *apiService {
	dir, err := api.Dir()
	s := &apiService{cfg: cfg, ag: ag, dir: dir}
	if err != nil {
		s.status.Err = err.Error()
	}
	ag.API = s
	return s
}

// StartIfEnabled is the startup call: nothing happens with api.enabled off.
func (s *apiService) StartIfEnabled() {
	if !s.cfg.API.Enabled {
		return
	}
	if err := s.Start(); err != nil {
		s.ag.QueueNotice("api: " + err.Error())
	}
}

func (s *apiService) Start() error {
	s.mu.Lock()
	defer s.mu.Unlock()
	if s.srv != nil {
		return nil
	}
	if s.status.Err != "" && s.dir == "" {
		return errors.New(s.status.Err)
	}
	timeout, err := time.ParseDuration(s.cfg.API.Timeout)
	if err != nil || timeout <= 0 {
		timeout = 120 * time.Second
	}
	code := ""
	if s.ag.Session != nil {
		code = s.ag.Session.ResumeCode()
	}
	ln, err := api.Listen(s.dir, api.Record{PID: os.Getpid(), SessionCode: code})
	if err != nil {
		var se *api.ServedElsewhere
		if errors.As(err, &se) {
			s.status = agent.APIStatus{ServedBy: se.Record.SessionCode, ServedByPID: se.Record.PID, Socket: se.Record.Socket, Err: err.Error()}
		} else {
			s.status = agent.APIStatus{Err: err.Error()}
		}
		return err
	}
	reg := api.NewRegistry(s.dir + "/apps")
	reg.Warn = func(msg string) { s.ag.QueueNotice(msg) }
	logf, _ := os.OpenFile(s.dir+"/access.log", os.O_CREATE|os.O_APPEND|os.O_WRONLY, 0o600)
	srv := api.New(api.Options{Backend: agent.NewAPIBackend(s.ag, Version), Apps: reg, Timeout: timeout, AccessLog: logf})
	s.srv, s.ln = srv, ln
	s.status = agent.APIStatus{Serving: true, Socket: api.SocketPath(s.dir)}
	go func() {
		_ = srv.Serve(ln)
		if logf != nil {
			logf.Close()
		}
	}()
	return nil
}

func (s *apiService) Stop() {

// APICommand is /api, /api on and /api off: the serving state of the
// application API for this session, and the per-session switch (it never
// writes config).
func APICommand(ag *agent.Agent, fields []string) string {
	if ag.API == nil {
		return "this session cannot serve the application API (headless runs never do)"
	}
	if len(fields) > 1 {
		switch fields[1] {
		case "on":
			if err := ag.API.Start(); err != nil {
				return "api: " + err.Error()
			}
			return "api: serving on " + ag.API.Status().Socket
		case "off":
			ag.API.Stop()
			return "api: stopped for this session"
		default:
			return "usage: /api [on|off]"
		}
	}
	st := ag.API.Status()
	var b strings.Builder
	switch {
	case st.Serving:
		fmt.Fprintf(&b, "api: serving on %s\n", st.Socket)
		fmt.Fprintf(&b, "  %d requests this session", st.Served)
		if st.LastApp != "" {
			fmt.Fprintf(&b, "; last from %s at %s", st.LastApp, st.LastAt.Format("15:04:05"))
		}
		if st.InFlight != "" {
			fmt.Fprintf(&b, "; %s is in flight", st.InFlight)
		}
	case st.ServedBy != "":
		fmt.Fprintf(&b, "api: not serving; session %s (pid %d) serves on %s", st.ServedBy, st.ServedByPID, st.Socket)
	default:
		if dir, derr := api.Dir(); derr == nil {
			if rec, ok := api.Serving(dir); ok {
				fmt.Fprintf(&b, "api: not serving; session %s (pid %d) serves on %s", rec.SessionCode, rec.PID, rec.Socket)
				return b.String()
			}
		}
		b.WriteString("api: not serving (api.enabled is off; /api on serves from this session)")
		if st.Err != "" {
			b.WriteString("\n  " + st.Err)
		}
	}
	return b.String()
}

// AppsCommand is /apps: the registered apps and when each last called.
func AppsCommand() string {
	dir, err := api.Dir()
	if err != nil {
		return "apps: " + err.Error()
	}
	apps, err := api.NewRegistry(dir + "/apps").List()
	if err != nil {
		return "apps: " + err.Error()
	}
	if len(apps) == 0 {
		return "no apps registered; `be-code apps add <name>` registers one"
	}
	var b strings.Builder
	for _, a := range apps {
		state := strings.Join(a.Profile.Tiers, ",")
		if a.Revoked != nil {
			state = "revoked"
		}
		fmt.Fprintf(&b, "%-20s %-20s sessions: %s\n", a.Name, state, a.Profile.Sessions)
	}
	return strings.TrimRight(b.String(), "\n")
}

// SessionCommand is /session token and /session rotate [grace]. The secret
// comes back on its own so a UI can show it without ever storing it; the
// note is safe to render anywhere.
func SessionCommand(ag *agent.Agent, fields []string) (secret, note string, err error) {
	if len(fields) < 2 {
		return "", "", errors.New("usage: /session token | /session rotate [grace]")
	}
	switch fields[1] {
	case "token":
		tok, err := ag.SessionToken()
		if err != nil {
			return "", "", err
		}
		return tok, "this session's API token (apps send it as X-BE-Session); /session rotate replaces it", nil
	case "rotate":
		grace := time.Duration(0)
		if len(fields) > 2 {
			d, perr := time.ParseDuration(fields[2])
			if perr != nil {
				return "", "", fmt.Errorf("grace %q: %w", fields[2], perr)
			}
			grace = d
		}
		if grace > store.MaxTokenGrace {
			return "", "", fmt.Errorf("grace %s is over the 24h limit", grace)
		}
		tok, err := ag.RotateSessionToken(grace)
		if err != nil {
			return "", "", err
		}
		if grace > 0 {
			return tok, fmt.Sprintf("token rotated; the old one keeps working for %s", grace), nil
		}
		return tok, "token rotated; the old one has stopped", nil
	}
	return "", "", fmt.Errorf("unknown /session verb %q (token, rotate)", fields[1])
}

- [ ] **Step 3: Write `test/e2e/api_e2e.sh`**

Run from `run_e2e.sh` with the mock server already up and `$HOME` pointing at the suite's
config (which `run_e2e.sh` exports). A headless run first creates a saved session, whose token
`be-code session token` mints while nobody hosts it; a plain session then resumes that session
with the API on, its stdin held open on a fifo, and the client exercises the socket.

```sh
#!/bin/sh
# Application API scenario: a plain session serves the API; the client
# exercises every endpoint and the refusals over the unix socket.
set -e
BIN="$(dirname "$0")/../../be-code"
WS=$(mktemp -d); trap 'rm -rf "$WS"' EXIT
printf 'module example.com/api\n\ngo 1.22\n' > "$WS/go.mod"

# api.enabled on, everything else as the suite's config.
python3 - "$HOME/.be-code/config.json" <<'PY'
import json, sys
p = sys.argv[1]; c = json.load(open(p)); c["api"] = {"enabled": True, "timeout": "30s"}
json.dump(c, open(p, "w"))
PY

KEY=$("$BIN" apps add e2e-app --tiers query,completions --sessions named | sed -n 's/^  \(bek_1_.*\)$/\1/p')
[ -n "$KEY" ] || { echo "apps add printed no key"; exit 1; }

# A saved session to serve: headless, so nobody hosts its file afterwards.
"$BIN" run -y -C "$WS" "api scenario: warm up" > /dev/null
CODE=$("$BIN" sessions | awk 'NR==2 {print $1}')
[ -n "$CODE" ] || { echo "no saved session"; exit 1; }
TOKEN=$("$BIN" session token "$CODE" --stdout)
[ -n "$TOKEN" ] || { echo "no session token"; exit 1; }

# The plain session resumes it with stdin held open: the REPL serves while it waits for a line.
FIFO="$WS/in"; mkfifo "$FIFO"
"$BIN" --plain --resume "$CODE" -C "$WS" < "$FIFO" > "$WS/session.log" 2>&1 &
SESSION=$!
exec 3>"$FIFO"

SOCK="$HOME/.be-code/api/api.sock"
for i in $(seq 1 50); do [ -S "$SOCK" ] && break; sleep 0.2; done
[ -S "$SOCK" ] || { echo "the API socket never appeared"; cat "$WS/session.log"; exit 1; }

python3 "$(dirname "$0")/api_client.py" "$SOCK" "$KEY" "$TOKEN"

printf '/quit\n' >&3
exec 3>&-
wait $SESSION || true
[ ! -S "$SOCK" ] || { echo "the socket outlived the session"; exit 1; }
grep -q "app=e2e-app" "$HOME/.be-code/api/access.log" || { echo "no access log line"; exit 1; }
! grep -q "$KEY" "$HOME/.be-code/api/access.log" || { echo "the key reached the access log"; exit 1; }
! grep -q "$TOKEN" "$HOME/.be-code/api/access.log" || { echo "the token reached the access log"; exit 1; }
echo "[PASS] api"
```

`--resume` of a session whose saved `host_pid` is a finished headless run is the ordinary resume
path (a dead pid is ignored by the save guard). The `--stdout` flag is what makes `session token`
print into a command substitution.

Add before `## Scheduled events` (line 529):

```markdown
## Application API

Other programs on this machine can ask a running session for an answer. An interactive
session with `api.enabled: true` (or `/api on`) serves `~/.be-code/api/api.sock`; one session
serves per machine, and a second one says which. Headless runs never serve.

Register the caller once and keep the key it prints — it is shown once and only its hash is
stored:

```bash
be-code apps add ue5-helper --tiers query,completions --packs ue5 --sessions named
```

Three things a caller can ask for, each with `Authorization: Bearer <key>`:

- `POST /v1/query` `{prompt, system?, model?, pack?, json_schema?, max_tokens?}` → one answer
  with no tools and no history; `pack` puts an active pack's rules in front of `system`;
  `json_schema` has the reply checked on the way out (422 `schema_mismatch` with the text).
- `POST /v1/chat/completions` — the OpenAI shape, streaming with `stream: true`. Point an
  existing OpenAI client at the socket with `base_url` and the key as `api_key`; `model:
  "default"` is the session's model. Requests with `tools` or `n > 1` are refused with
  `not_supported`, since this tier serves inference only.
- `POST /v1/sessions/<token>/query` — the same question answered with the serving session's
  conversation as context, never appended to it. The token is `/session token` in the session
  (or `be-code session token <code>` for one that is not running), sent as `X-BE-Session`;
  `/session rotate [grace]` replaces it. Browser and web page text in the conversation is
  withheld from the caller.

An app's profile bounds it: tiers, models (`default` is always allowed), packs, whether it may
name a session, and a budget (`tokens` per reply, `per_hour` requests; 429 with `Retry-After`
past it). `be-code apps list|show|rotate|revoke|remove` manage apps; `revoke` takes effect
without restarting the serving session. Requests carrying `Origin` or `Sec-Fetch-Mode` are
refused: the API is for programs, not pages. `~/.be-code/api` must be mode 0700 on Unix, and
on Windows the directory's ACL is the boundary. The access log at `~/.be-code/api/access.log`
names apps and session codes, never keys or tokens.

A request on the session's own model makes the server's prompt cache cold for the person's next
turn; the session re-reads its prompt in the background afterwards, so the cost that remains
is the request's own. A streamed completion's chunks carry the requested model name; the final
response carries the resolved one. An older build that resaves a session drops its token, and
the app must fetch a new one.
```

In the config reference, after the `schedules` block:

```markdown
- `api.enabled` (false) — serve the application API from interactive sessions; `api.timeout`
  (`120s`) bounds one request. Everything per-app is in `~/.be-code/api/apps/<name>.json`.
```
